PUBLICAR GRATIS EN GITHUB PAGES
1. Entra en https://github.com e inicia sesión.
2. Pulsa el signo + y elige New repository.
3. Ponle un nombre, por ejemplo: venta-cacao-yubi-cruz
4. Selecciona Public y crea el repositorio.
5. Pulsa Add file > Upload files.
6. Sube index.html y la carpeta assets completa (con las dos imágenes).
7. Pulsa Commit changes.
8. En el repositorio abre Settings > Pages.
9. En Build and deployment selecciona Deploy from a branch.
10. Elige la rama main y la carpeta /(root), y pulsa Save.
11. GitHub generará una dirección pública con formato https://TU-USUARIO.github.io/venta-cacao-yubi-cruz/
